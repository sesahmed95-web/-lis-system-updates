# تشغيل برنامج مختبر أمراض الدم

## التثبيت (مرة واحدة فقط)
1. فكّ ضغط هذا المجلد بأي مكان على جهازك.
2. ادخل المجلد `lis_system` واضغط دبل كلك على **install.bat**.
3. انتظر لين تطلعلك رسالة "تم التثبيت بنجاح" — بهذه اللحظة تكون طلعت أيقونة جديدة
   بسطح المكتب اسمها **"برنامج مختبر أمراض الدم"**.
4. بعدها تكدر تحذف المجلد الأصلي (اللي فكيته بالخطوة 1) — البرنامج الحين نسخة
   دائمة على جهازك ومو مرتبط بذاك المجلد.

هذا الملف (install.bat) عادي، مو VBS — يشتغل حتى إذا الـ Windows Script Host
مو مفعّل على جهازك.

## الاستخدام اليومي
من الحين وطالع، افتح البرنامج من أيقونة سطح المكتب بس — دبل كلك عليها
وينفتح مباشرة.

## إيقاف البرنامج
إذا احتجت توقف السيرفر يدويًا (نادرًا ما تحتاجها)، افتح مجلد التثبيت
(`%LOCALAPPDATA%\HematologistLIS`) وشغّل `stop.ps1` بالضغط عليه بزر الماوس
اليمين → Run with PowerShell.

## أول مرة تشغل البرنامج
لازم يكون عندك Python مثبت على الجهاز (من https://www.python.org/downloads/،
وفعّل خيار "Add python.exe to PATH" أثناء التثبيت). أول تشغيل يحتاج اتصال
إنترنت لمرة وحدة بس عشان ينزّل المكتبات المطلوبة تلقائيًا.
