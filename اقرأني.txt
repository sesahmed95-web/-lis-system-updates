حزمة التحديث الكاملة (v38 + كل التعديلات). كل ملف بمساره الصحيح داخل مجلد البرنامج.

للمصمم (على جهازك):
1) انسخ كل الملفات فوق مجلد البرنامج (نفس المسارات) واقبل الاستبدال.
2) شغّل build.bat  ->  dist\LabSystem\LabSystem.exe
3) افتح installer.iss بـ Inno Setup واضغط Ctrl+F9  ->  installer_output\LabSystem_Setup.exe
4) أرسل للعميل LabSystem_Setup.exe فقط. يثبّته فوق النسخة القديمة (نفس المجلد) وبياناته (lis.db) تبقى.

ملاحظة: نسخة Setup المثبّتة ملفاتها داخل الـexe، فنسخ ملفات .py/.html عند العميل ما يغيّر شي. أي تعديل لازم يتبنى بـ Setup جديد.

open_network.bat: للجهاز الرئيسي عند العميل (تشغيل كمسؤول) — يفتح منفذ 9090 ويعرض عنوان الجهاز.
.gitignore: لمجلد GitHub فقط (ما يدخل بالـSetup).

--- تعديلات هذي الدفعة ---
1) زيارة جديدة: خانة "دفع كامل" بجانب الواصل (تأشير = الواصل = المبلغ الكلي)، وكتابة مبلغ أقل تنزّل الفرق بالباقي. سنة الميلاد تحسب العمر تلقائيًا. حذفت حقل "وقت ظهور النتائج المتوقع".
2) منع تكرار الزيارة: بعد الحفظ زر الحفظ يتعطل لين تضغط "زيارة جديدة أخرى" (كان الضغط مرة ثانية ينشئ زيارة جديدة برقم جديد).
3) الباركود: التحاليل بنفس القسم (department) تاخذ باركود واحد. حقل "عدد الباركود" بزيارة جديدة يحدد عدد النسخ. للرجوع للتجميع القديم حسب نوع العينة: ?group=sample_type أو إعداد barcode_group_mode.
4) صفحة الزيارات (front_desk/visits.html): عمود Test فيه كل تحاليل الزيارة وسعر كل تحليل.
5) بدون نافذة سوداء: build.bat يبني --noconsole، والأيقونة تشغّل start_lab.vbs (يشغّل السيرفر مخفي وينتظر لين يجهز ثم يفتح المتصفح). لإيقاف البرنامج: Stop Lab System من قائمة ابدأ (stop_lab.bat). سجل الأخطاء: server_log.txt بمجلد التنصيب.
6) start_lab.vbs يفتح البرنامج بنافذة Edge (وضع التطبيق، بدون تبويبات)، وإذا Edge مو موجود يفتح المتصفح الافتراضي.
7) الباركود: ما يطبع اسم القسم، يطبع أسماء التحاليل (وللتحليل الجزئي أسماء البارامترات المختارة فقط، بدون Control وINR). زيارة جديدة: اختيار PT يختار PT Control وINR تلقائيًا، واختيار PTT يختار PTT Control (يُلغى معه عند إلغائه).
8) تعديل الزيارة: تغيير الطبيب المُحيل ما يعيد تسعير التحاليل الجزئية (PT/PTT..) بسعر التحليل كامل (كان يزيد الإجمالي ويظهر باقي).
9) print_sample_barcodes.html: سطر العنوان (نوع العينة/القسم) يظهر فقط إذا فيه قيمة، فما يبقى سطر فاضي على الملصق.
10) زيارة جديدة: زر "QR المريض" (يتفعّل بعد الحفظ) وزر "وقت النتائج المتوقع" (يختار وقت أو +1/+2/+4 ساعات/غداً). صفحة النتائج: طباعة كل النتائج/اللوحة المجمّعة تحفظ تلقائيًا ثم تفتح التقرير بنافذة حقيقية (الطباعة داخل iframe ما تشتغل بنافذة Edge بوضع التطبيق).
11) installer.iss و open_network.bat: يفتحون أيضًا المنفذ 5000 (ربط أجهزة المختبر ASTM). إذا غيّرت المنفذ من Host Interface لازم تفتح المنفذ الجديد بجدار الحماية.
12) astm_host.py: ردّ الاستعلام يرسل تاريخ الميلاد (P.8، صيغة YYYYMMDD) حتى الجهاز يختار المدى الطبيعي حسب العمر؛ لو التاريخ غير مسجّل يُشتق من العمر ووحدته. بعد النسخ أعد تشغيل البرنامج.
