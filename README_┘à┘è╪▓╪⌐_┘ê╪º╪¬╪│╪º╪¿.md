# إرسال النتائج عبر واتساب — دليل التشغيل

## شنو انضاف؟
- زر **📱 إرسال هذه النتيجة واتساب** أمام كل تحليل بصفحة إدخال النتائج
  (يرسل نتيجة واحدة فقط بملف PDF).
- زر **📱 إرسال كل النتائج واتساب** أعلى نفس الصفحة (يرسل كل نتائج
  الزيارة مجموعة بملف PDF واحد).
- صفحة **📱 طابور واتساب** (بالقائمة الجانبية، للمشرف/الأدمن) تعرض كل
  عمليات الإرسال وحالتها (تم / بالانتظار / فشلت) مع زر إعادة محاولة.
- البرنامج يبقى **محلي بالكامل** — الإرسال نفسه فقط يحتاج إنترنت وقته،
  وإذا ما كان متوفر تنضاف العملية لطابور وتُعاد المحاولة تلقائيًا كل ٣
  دقائق فور رجوع الإنترنت (مو مطلوب حدا يقعد ينتظر).

## طريقة الإرسال المستخدمة
تم اعتماد **أتمتة WhatsApp Web** (بدون أي اشتراك أو API مدفوع) بناءً على
اختيارك. هذا يعني:

- ما فيه رسوم شهرية أو تسجيل حساب Business.
- لازم يكون على جهاز السيرفر متصفح **Google Chrome** مثبّت.
- أول مرة فقط تفتح نافذة Chrome وتطلب مسح رمز **QR** — يُمسح من نفس
  رقم واتساب المختبر (يُفضّل رقم مخصص للمختبر مو رقم شخصي). بعدها
  الجلسة تُحفظ بمجلد `whatsapp_profile/` جنب البرنامج وما تطلب QR مرة
  ثانية إلا إذا سُجّل الخروج يدويًا.
- هذا أسلوب غير رسمي وغير مدعوم من واتساب نفسه، فيه احتمال بسيط لحظر
  الرقم لو استُخدم بكثافة عالية جدًا أو بشكل آلي مبالغ فيه — طبيعي
  ومتوقع لمختبر بحجم عادي.

## خطوات التثبيت لمرة وحدة
1. تثبيت المتطلبات الجديدة:
   ```
   pip install -r requirements.txt
   playwright install chromium
   ```
2. تأكد إن Google Chrome مثبّت على جهاز السيرفر (لأتمتة واتساب ويب).
3. شغّل البرنامج عادي (`run.ps1` أو `run_windows.bat`).
4. أول عملية إرسال واتساب راح تفتح نافذة Chrome تلقائيًا وتطلب مسح QR
   — امسحه من موبايل المختبر (واتساب ← الأجهزة المرتبطة ← ربط جهاز).
5. من **الإدارة ← الإعدادات** حدّد كود الدولة (افتراضيًا 964 للعراق)
   حتى تتحول أرقام المرضى المحلية (اللي تبدأ بصفر) لصيغة دولية صحيحة.

## ملاحظات مهمة
- يجب أن يكون رقم هاتف المريض مسجّل بملفه الشخصي وإلا ما يظهر زر
  الإرسال.
- الإرسال يشتغل فقط للنتائج بحالة **مكتملة** أو **معتمدة**.
- الـPDF المُرسل هو نفسه شكل صفحة الطباعة تمامًا (نفس الشعار والتصميم)
  — أي تعديل تسويه على تصميم التقرير من "مصمم التقارير" ينعكس تلقائيًا
  على الـPDF المُرسل.
- لملف الإعدادات المستقبلية: لو حبيت تتحول لاحقًا لمزوّد رسمي (Twilio
  أو WhatsApp Cloud API) بدل أتمتة WhatsApp Web، يكفي تغيير محتوى
  `whatsapp_bridge.py` فقط — بقية البرنامج (الطابور، الأزرار، توليد
  الـPDF) ما يحتاج أي تعديل.
